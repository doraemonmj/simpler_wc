# PyPTO 3.0 IDE 学习

这里专门梳理 **PyPTO 3.0 框架产物**在 PyPTO3 Toolkit 中的查看路径。`3.0` 指框架代际，不是 VS Code 扩展的版本号。先前按旧插件源码整理的 `program.json`、计算图、OpCheck 等能力，不作为本目录的主线。

## 总览

- [PyPTO 3.0 IDE 现状](现状.md)：版本基线、模块地图、与旧插件路径的差别，以及当前兼容边界。
- [PyPTO 3.0 输入数据结构](数据结构.md)：Chip Swimlane、依赖图、名称映射、CPM、IR Pass、Memory Map、Serving 泳道需要的文件和字段。
